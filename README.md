# JanSetu AI — Track 1 Prototype

A clickable frontend prototype for **AI for Digital Public Infrastructure & Governance**.

## Core idea
JanSetu AI is an AI governance layer that sits above existing public-service systems. It helps citizens discover services and track requests, while helping officials triage grievances and monitor service delivery.

## Demo flows
1. Overview → governance command center
2. Citizen Services → AI service navigator + consent ledger
3. Grievance AI → complaint classification + human approval
4. Governance Copilot → SLA risk, fairness monitoring, audit records
5. Impact Analytics → illustrative impact metrics

## Run
Open `index.html` directly in Chrome/Edge, or serve the folder:
`python -m http.server 8000`

Then visit `http://localhost:8000`.

## Important
All data and metrics are mock data for demonstration. No real citizen information is used.
